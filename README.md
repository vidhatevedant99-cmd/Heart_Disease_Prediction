# ❤️ Heart Disease Prediction using Logistic Regression

## 📌 Project Overview

This project predicts whether a patient is likely to have heart disease using **Logistic Regression**. The model was built using **Scikit-learn** and follows a professional machine learning workflow with **Pipeline** and **ColumnTransformer** for preprocessing.

This project was created as my first end-to-end machine learning project while learning supervised machine learning.

---

## 📂 Dataset

* **Dataset:** UCI Heart Disease Dataset
* The dataset contains patient information such as:

  * Age
  * Sex
  * Chest Pain Type
  * Blood Pressure
  * Cholesterol
  * ECG Results
  * Exercise Induced Angina
  * Maximum Heart Rate
  * Oldpeak
  * and other medical attributes.
