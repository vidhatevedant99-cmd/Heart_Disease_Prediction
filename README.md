❤️ Heart Disease Prediction

📌 Overview
A machine learning project that predicts the likelihood of heart disease using Logistic Regression. The project demonstrates data preprocessing, feature engineering, model training, and evaluation using Scikit-learn Pipelines.

📂 Dataset
• UCI Heart Disease Dataset

🛠 Technologies
• Python
• Pandas
• NumPy
• Matplotlib
• Scikit-learn

⚙️ Workflow
• Data Cleaning
• Missing Value Handling
• One-Hot Encoding
• Train-Test Split
• Pipeline
• Logistic Regression
• Model Evaluation

📊 Result
Accuracy: 83%

🚀 How to Run
1. Install dependencies.
2. Open the notebook.
3. Run all cells.
